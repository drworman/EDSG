# Images

## Avatars

Generated by `scripts/generate_icons.py` — do not edit them by hand. To change
the artwork, edit the script and re-run it from the repository root:

```bash
python scripts/generate_icons.py
```

| File | Use |
|---|---|
| `edsg_avatar_512.png` | README header, GitHub social preview, Discord |
| `edsg_avatar_4096.png` | Print, high-DPI, source for derivative art |
| `edsg_avatar_<colour>_*.png` | Alternative accents: green, blue, purple, red, yellow, light |

The unsuffixed files are the orange default, matching the application theme.
The same script also writes the packaged icons under `packaging/icons/`.

## Screenshots

The three screenshot files in this folder are **placeholders**, so the README
renders cleanly on a fresh clone. Replace each with a real capture:

| File | What to capture |
|---|---|
| `screenshot_organizer.png` | Organizer, Criteria tab, with several criteria defined |
| `screenshot_participant.png` | Participant after a scan, results table populated |
| `screenshot_standings.png` | An HTML standings report open in a browser |
